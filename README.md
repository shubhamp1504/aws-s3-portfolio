# AWS S3 Static Portfolio Website

## Project Overview

This project hosts a static portfolio website using Amazon S3 and CloudFront.

## Technologies Used

- HTML5
- CSS3
- AWS S3
- AWS CloudFront
- Git
- GitHub

## Features

- Responsive Portfolio
- Hero Section
- About Section
- Skills Section
- Projects Section
- Contact Section
- HTTPS using CloudFront

## Project Structure

```
index.html
style.css
README.md
```

## Steps Performed

1. Created an S3 bucket.
2. Disabled Block Public Access.
3. Enabled Static Website Hosting.
4. Uploaded HTML, CSS, and images.
5. Added Bucket Policy.
6. Created a CloudFront Distribution.
7. Tested the website.
8. Uploaded project to GitHub.
